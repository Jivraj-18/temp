LLM-Powered Financial Fundamentals Solution

Converting financial reports into comparable, auditable ratios and sector-specific performance indicators

PURPOSE
Turn financial statements into comparable, auditable ratios for investment, credit, indexing, benchmarking and trend analysis.

Executive Summary
The solution uses a context-aware large language model (LLM) to identify and extract financial values from annual reports, 10-Ks, 10-Qs and other key company reports. It then normalizes the extracted data and uses a ratio engine to calculate general financial ratios, sector-specific ratios and key performance indicators (KPIs). Source-linked evidence and a human-in-the-loop quality layer support traceability and review, particularly where disclosures are ambiguous or require judgment.
The business value is a more scalable and consistent way to transform unstructured financial disclosures into standardized fundamental data that can support downstream analysis and decision-making.

Why MSCI Would Need This Solution

  • Scale financial data coverage: support processing across a broad range of issuers, report types and reporting periods.
  • Improve comparability: normalize values and apply consistent calculation logic so ratios can be compared across companies and over time.
  • Enable richer analytics: produce general ratios alongside sector-specific ratios and KPIs that reflect the relevant industry context.
  • Strengthen transparency and auditability: link extracted values to their source locations so users and reviewers can trace how a result was derived.
  • Balance automation with quality: use human review for complex, ambiguous or low-confidence cases rather than relying on automation alone.
  • Support multiple use cases: provide structured inputs for investment research, credit analysis, indexing, benchmarking and trend analysis.

The Gap the App Addresses

Financial information is published in reports that vary in format, terminology, structure, level of detail and sector-specific disclosure. Turning those disclosures into consistent analytical data can require substantial manual effort and interpretation.

Demo Script

Step 1: Access the Application

Open the application using the link below:

https://jivraj-18.github.io/temp/demos/fundamental-data/index.html

Step 2: Take the Guided Tour
Click on the “Take the Tour” option to get a brief overview of the application, its key features, and navigation.

Step 3: Select the Issuer/Company

Use the issuer selection option located in the upper-right corner of the page to select the company whose financial data you wish to explore.

Step 4: Access the Source Document

Click on the highlighted text to view the source document from which the financial values have been extracted. This enables users to refer to the original disclosure supporting the extracted data.

Step 5: Review Issuer Details

Review the issuer information displayed below the issuer name to understand the company’s profile and relevant details.

Step 6: Explore the Available Data Sets

Select the relevant option to explore the required financial data set:

  1. General Ratios: Review commonly used financial ratios for evaluating a company's financial performance and position.
  2. Sector-Specific Ratios: Explore financial ratios tailored to the relevant industry or sector.
  3. Financial Indicators / Financial Data Points: Review the underlying financial values and data points extracted from the source reports.
  4. Formulas: Examine the formulas used to calculate the financial ratios.

Step 7: Review Source Annotations

Click on the highlighted text associated with an extracted value to view its annotation in the source document. This helps users trace the extracted value back to the relevant source evidence and supports verification.

Step 8: Explore Sector Benchmarks

Click on the “Sector Benchmark” option to explore sector-level analysis and compare financial performance across companies within a sector or across different sectors.

2. How It Works (Process)

  1. Data Collection: Retrieve financial filings and relevant company information from identified sources.
  2. Data Extraction: Extract financial statements, key financial line items and relevant disclosures using AI/LLM-based processing.
  3. Data Normalization: Standardize financial data across reporting formats, currencies, units and periods.
  4. Financial Analysis: Calculate general and sector-specific financial ratios and KPIs.
  5. Validation & Quality Checks: Apply automated validations and human review to ensure data accuracy, completeness and traceability.

3. Live Tool (Outputs & Demonstration)

  • Structured Financial Data: Company fundamentals, financial line items, ratios and KPIs.
  • Source Traceability: Navigate from extracted values to the relevant source documents and supporting text.
  • Data Access: View and export structured outputs through the application, with available download or integration options.
  • Live Demonstration: Select a company, review extracted financial data, inspect source evidence, and validate the generated ratios and KPIs.

Project Objective: To transform financial reports into structured, standardized, and traceable fundamental data through AI-powered extraction, financial analysis and human quality validation.
